# VisaGo 使用文档

签证预约与材料代交服务：客户在线下单、上传护照、拿到收款码付款，后台确认收款后由签证专员预约递签、上传预约信。

## 跑起来

本地开发：

```bash
bun install
cp .env.example .env      # 改掉 ADMIN_EMAIL / ADMIN_PASSWORD
bun run serve             # http://127.0.0.1:3300
bun run build             # 改完前端要重新构建，服务端直接重启即可
```

服务器上（docker compose，`./data` 挂到容器里，重启不丢数据）：

```bash
docker compose up -d --build
```

环境变量：

| 变量 | 作用 |
| --- | --- |
| `ADMIN_EMAIL` / `ADMIN_PASSWORD` | 后台账号，第一次启动时创建；之后改这里不会改已有密码 |
| `PORT` / `SERVER_PORT` | 服务端口，默认 3300 |
| `DATA_DIR` | 数据目录，默认 `./data`；订单在 `data/*.jsonl`，上传的图片在 `data/uploads` |
| `ALIYUN_OCR_ACCESS_KEY_ID` / `_SECRET` | 护照识别，不配也能用，只是不能拍照识别 |
| `ALIYUN_OCR_ENDPOINT` | 默认 `ocr-api.cn-hangzhou.aliyuncs.com` |

## 客户下单

1. 首页点「开始申请」，填邮箱和姓名确认身份。同一个邮箱再来，直接看到历史订单，点「再订一单」开新单。
2. 走 6 步：选择国家 → 出行人数 → 护照信息 → 递签日期 → 出行计划 → 确认订单。
   - 护照可以拍照识别（要配 OCR），也可以手动填。拍的照片会存下来，后台能看原件。
   - 递签日期只能从签证中心已开放的日期里选；绿色正常、橙色拥挤、灰色不可选。
3. 提交后订单状态是**待处理**，页面直接给收款码（按金额匹配，匹配不上用兜底码）。
4. 订单页随时可以改出行日期、备注；订单一旦被后台**锁定**就改不了。
5. 多人订单可以复制同行人链接发给对方，对方自己补护照（订单锁定后这个链接不再显示）。
6. 锁定后申根订单会多一张「签证申请表」卡片，点开是麦克表单，填完由后台勾「表单已填」。

订单页地址是 `/order/<邀请码>`，查看密钥存在浏览器里，换设备要用下单邮箱和姓名重新确认身份。

## 后台

登录 `/auth`，进「Orders」。

### 订单列表

- 可按出发地、目的地、关键词（订单号、姓名、邮箱、护照号、城市、备注）筛选，每页 10 条。
- **待修改**的订单排在最前面。

### 订单详情

- **确认收款并锁定**：待处理的单确认收到钱后锁定，半小时后自动转「预约中」。
- 状态按钮：预约中 / 排号中 / 刷位中 / 待修改 / 退回待处理 / 取消订单。
  - 排号中、刷位中只是标注，不影响别的流程。
  - **待修改**会弹窗让你写「修改目标」，必填，客户订单页能看到这段话。
- 预约到的位置、备注、候选递签日期都能直接改；上传预约信 PDF 后自动识别日期并填入，同时订单变**已完成**。
- 每位出行人旁边有「表单已填」勾选框，客户页会显示还差谁。
- 护照信息里「护照原件」点「查看」弹窗看照片，只有客户上传过才有。
- 已取消的订单可以归档，归档的在「已归档」里，可恢复。

### 状态说明

| 状态 | 含义 |
| --- | --- |
| 待处理 | 刚下单，等收款 |
| 已锁定 | 收到款，等 30 分钟自动转预约中 |
| 预约中 | 专员在排预约 |
| 排号中 / 刷位中 | 纯标注 |
| 待修改 | 材料有问题，等客户改，列表置顶 |
| 已完成 | 预约信已上传 |
| 已取消 | 已取消，可归档 |

### 收款码

「收款码」页维护金额对应的收款码图片。同一金额有多张时用最新的那张；设一张「兜底码」，金额对不上时用它。英国订单按当天汇率折成人民币再匹配。

### 签证配置

「Visa」页（签证配置）按出发国 × 目的地维护：

- 签证费（每人）
- 签证中心列表，以及每个中心的**正常**日期和**拥挤**日期
- 材料组排期（几个工作日），决定最早能约到哪天

排期可以手工点，也可以截图粘贴或直接粘 VFS 排期 JSON：重复日期 2–4 次算拥挤，5 次以上算正常，只覆盖这份数据里出现的月份。

### 设置

- **通知**：填企业微信机器人地址、会话 ID、会话类型和令牌，新订单会推一条；配好可以发测试消息。
- **数据备份**：导出 JSON（含全部订单、客户、收款码、配置和文件），导入是整库替换，不是合并。

## 数据

- `data/visa-order.jsonl` 等是明文 JSON，一行一条，改之前先停服务。
- `data/uploads/` 存护照照片和预约信 PDF，别单独删，订单会引用里面的文件。
- 迁移或换机器：导出备份，或者整个 `data/` 目录打包带走。

## 常见问题

**客户说看不到护照照片？** 只有在下单时拍照上传（或在订单页点出行人重新上传）才会存，纯手填的订单没有照片。

**订单锁定后客户要改怎么办？** 后台点「退回待处理」，客户就能改，改完再锁定。

**为什么客户选不了日期？** 该中心没有开放日期，或者开放日期都在材料组排期之外。去「Visa」页检查这个中心的日期。

**收不到新订单通知？** 设置页四个字段（地址、会话 ID、令牌，会话类型可留自动）缺一个就不发；先用「发条测试消息」验证。
